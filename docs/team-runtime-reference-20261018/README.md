# 团队配置与复现日志（2026-10-18）

[配置参考](configuration.json)保留当前本机工作台的模型、预算、五个本地资源角色、业务端口，以及现存域环境文件的字段。Python 路径改为项目相对引用，native 机器路径与进程状态改为项目占位符；环境文件仅保留数据库主机、端口、数据库与用户名，其余值由接手者自行填写。原运行配置与密码不变。

这是当前 Windows native / local-aip-stdio 环境的资料快照，不能直接作为 NEW7 正式平台配置，也不要整体覆盖自己的 native-runtime.json。按[接手指南](../开发者接手指南_20261018.md)建立自己的虚拟环境，再用现有配置工具和部署入口生成本机文件；模型参数与预算可以按本页对照。正式 AIC、证书、私钥与 Inbox 归运行所有者管理，同一身份不能被多人同时消费。

[安装和离线日志](installation-and-offline-logs.md)包含两次安装、pip check、三个指定测试的输出和 Starlette 警告，只替换机器目录前缀。它们来自固定659b提交的新检出目录；修复后4项别名与15项启动器检查另见[本轮验证](../本地接手验证_20261018.md)，不能把两阶段当作同一提交的完整部署验收。
