## 创新三：本地60格的结论

| 方法 | 严格持续验收通过 | 模型调用 |
| --- | --- | --- |
| M0：固定观察、证据修复 | 15/15 | 0 |
| M1：自由工具调度 | 6/15 | 125 |
| M2v2：每事故一次假设生成 | 6/15 | 15 |
| MR：按公共症状盲修剧本 | 3/15 | 0 |

这是同5个故障家族、3组种子/连接池预置的本地实测，不是新故障家族泛化。60个唯一格分为原29格与接续31格，共61次尝试；1次执行器中断单独保留，不计为算法失败。

优化版减少了模型调用，但严格验收通过不足，尚不能宣称整体优于固定流程。6个双方通过配对的总耗时比中位数为1.216934，首次业务恢复时间比为1.552141；前者包含固定约30秒验证窗口，且不覆盖全部15配对，不能据此宣称整体达到1.3门槛。全部结果、失败、操作计数口径和图表见[本地60格报告](../evidence/p5-local60-20261020/README.md)。

本批发现并披露：稀疏候选预测导致优化调度过早停止；MR误分504；MR继续处理旧未知请求时，回执查询占用固定30次验证窗口的请求槽位。原结果不改判，后续比较须区分原请求收敛与新的30秒健康窗口。
