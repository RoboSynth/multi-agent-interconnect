# 接入体检使用说明

体检技能为 `aip.onboarding.check`，本队服务 AIC 为 `1.2.156.3088.1.0000.000000.000000.000000.0007`。通过梧桐 ADP 按该技能发现服务，取其 ACS 的 AIC 和 AMQPS Inbox 端点，再用自己的 AIC 和证书邀请它加入 AIP 群组。现有云部署已开启 `public_metadata_service:true`，文本和多群组运行时已上线；实际验收见文末。

服务只查询目标 AIC 的公开 ACS/ADP 元数据，检查协议02.02、官方ACS结构、技能字段和AMQPS Inbox格式；不连接目标端点，不持有数据库/服务器凭据，不验证目标私钥或实际证书用途。证书用途仍需目标方本机检查，不能把元数据通过写成mTLS运行通过。

## 输入和结果

原有 IFC 请求继续兼容。最小任务为：

```json
{"schema_version":"ifc/1.0","incident_id":"check-001","logical_task_id":"check-001:1","kind":"observe","tool":"aip.onboarding.check","args":{"target_aic":"替换为目标AIC","deep":false},"budget":{"deadline_ms":30000}}
```
返回 `facts[key=onboarding_report].value`，包含 `found/passed`、具体检查项及 `suggestions`。`tool_error`表示官方元数据查询失败，不能据此判目标配置错误。

公开体检的新运行时也接受一个 `TextDataItem` 内的普通文本，例如将下句的占位符替换为一个完整 AIC：

```text
请检查 <目标AIC> 的公开元数据
```

单一合法目标会转成 `observe / aip.onboarding.check`，并固定 `deep:false`；无需模型。没有目标、多目标、无效目标或文本超过 2000 字符时返回帮助，不查询 Discovery。识别到重启、修改资源、深探测、连通性或证书握手等请求时返回只读说明；任何文本都不能获得资源操作或目标端点探测能力。

文本请求的一个 Product 包含结构化 IFC 结果和中文 `TextDataItem` 摘要；原 IFC 请求仍只返回结构化项。调用方应按数据项类型读取，不把 JSON、文件或多个输入项混作一句话。当前公开 ACS 还只声明 JSON，`text/plain` 声明需按[ACS 更新说明](接入体检_ACS模式更新说明_20261020.md)由管理员处理；本地生成新声明不代表平台已更新。尚不能据此宣称叮当已调用成功。

## 使用自己的身份调用

本仓库的最小客户端默认只生成请求：

```powershell
python tools/onboarding_client.py --target-aic <目标AIC>
```
准备自己的私密caller.json，仅包含`leader:{aic,endpoint,cert,key}`、`trust_bundle`、`discovery_url`、`mq_auth_url`；证书路径可相对此配置文件。确认该调用身份没有其他消费者后，才实际运行：

```powershell
python tools/onboarding_client.py --target-aic <目标AIC> --service-aic <ADP返回的服务AIC> --config runtime/private/caller.json --output artifacts/onboarding-call-01 --execute
```
客户端会发现、描述确认、检查指定目标、正常关闭自建群组并保留日志。每次使用新输出目录；调用或关闭失败直接保留现场。

该客户端发送 IFC 请求；普通文本调用方使用官方 SDK 的 `start_task(task_content=文本)`，由 SDK 包装为 `TextDataItem`。不能直接往 Inbox 塞一段裸文本替代邀请和 AIP 任务流程。

## 提供方边界与容量

提供方只在体检域配置中显式设置`public_metadata_service:true`，保留自己的非空`allowed_leaders`、独立证书与日志目录，且不配置`env_file`。公开模式允许白名单外的合法调用 AIC 查询任意合法目标的公开元数据，仍校验认证发送方、群组 Leader、群组与会话、提及对象。其他资源域拒绝该开关，保持既有白名单限制。

新运行时最多同时接受 4 个活动群组，包含内部巡检组；内部 1 组常驻时，最多再接入 3 个外部组。满额时拒绝新邀请；同组重邀保留幂等行为，不额外占位。调用方结束后应正常关闭自建群组，释放服务名额。不同 Leader 使用同一 groupId 时明确拒绝冲突，保留已有组。

外部调用用`ops/longrun_status.py`的`--team-aic`列出七个本队身份后按接收端Start/taskId去重统计。元数据通过、平台在线、实际队外往返、排行榜记录分别留证。

配置生成入口均支持显式`--public-onboarding`：`domains/setup_platform.py`会要求已有独立体检身份；`deploy/prepare_agents.py`须同时带`--include-onboarding`；完整隔离部署用`deploy/prepare_deployment.py --mode seven`。这些入口仅准备配置，实际启用需重新部署；不带开关时默认关闭，容器生成器会保留来源配置中已经显式开启的值。
