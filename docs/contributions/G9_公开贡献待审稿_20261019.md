### Minimal local journal example

With this PR's SDK installed, this example writes a task attempt, reopens the same journal and reads its persisted state. It uses no broker or registered identity.

```python
from pathlib import Path
from tempfile import TemporaryDirectory
from acps_sdk.aip.resumable import TaskJournal

with TemporaryDirectory() as directory:
    path = Path(directory) / "tasks.sqlite"
    journal = TaskJournal(path)
    attempt = journal.record_attempt(
        "demo-check", session_id="demo-session", task_id="demo-task",
        partner_aic="synthetic-partner",
    )
    journal.transition(attempt, "working")
    reopened = TaskJournal(path)
    print(reopened.list_tasks(in_flight_only=True)[0]["state"])
```

Expected output: `working`.

For a live group, compose `ResumableGroupLeader(native_leader, journal)` with an already configured native leader. All writers for one resource domain must share its operation ledger; uncertain effects require inspection before retry. This PR's access cache is scoped to a middleware instance and its LRU lifetime. The later durable-access/process-recovery work and its 605-test combined suite are on the separate [integration branch](https://github.com/RoboSynth/ACPs-community/tree/integration/incident-ext-20261019), not this PR.

### Review scope and validation

At `72a994bfb8cd5cc832beb0204a4715a2c090f983`, the complete local `acps-sdk/tests` suite passed **558/558**, with exit code 0 and no skipped tests or collection/setup/teardown failures. The run retained one `PytestAssertRewriteWarning`. The shared MetricsEmitter test portability fix uses a temporary blocking file to trigger a real write error; product behavior is unchanged by that test fix.

MessageEmitter resolves its destination when constructed and shares a lock between instances targeting the same normalized path. The lock covers the complete append operation. This prevents interleaved records within one process while allowing different destinations to write independently. The five focused regressions cover path aliases, mixed synchronous/asynchronous writers, independent destinations, trace/schema preservation and lock release after write errors.

### Minimal local emitter example

With this PR's SDK installed, two instances can append message records to one destination:

```python
import json
from pathlib import Path
from tempfile import TemporaryDirectory
from acps_sdk.amp.message_emitter import MessageEmitter
from acps_sdk.amp.models import MessageBody, MessageDestination

with TemporaryDirectory() as directory:
    path = Path(directory) / "messages.jsonl"
    first = MessageEmitter(path, "synthetic-agent")
    second = MessageEmitter(path.parent / "." / path.name, "synthetic-agent")
    body = MessageBody(
        event_type="send", system="rabbitmq",
        destination=MessageDestination(name="synthetic", kind="exchange"),
    )
    first.emit_sync(body, trace_id="demo-trace")
    second.emit_sync(body, trace_id="demo-trace")
    rows = [json.loads(line) for line in path.read_text(encoding="utf-8").splitlines()]
    print(len(rows))
```

Expected output: `2`. This writes local log records; it does not publish RabbitMQ messages or send logs to Kafka. The lock is process-local. Cross-process durable access is separate integration-branch work and is not part of this PR's 558-test result.
