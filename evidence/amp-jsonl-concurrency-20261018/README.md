本批 AMP 坏行来自同一文件的并发追加竞争。官方 `MessageEmitter.emit()` 把同步写入交给 `asyncio.to_thread()`；发送、接收、确认路径可以同时写入。每次调用独立打开追加句柄，没有跨调用、跨实例的文件锁。本机 Windows 离线复现出现记录覆盖、尾片和已返回 `log_id` 的记录丢失；这不是 `FileHandler`。
