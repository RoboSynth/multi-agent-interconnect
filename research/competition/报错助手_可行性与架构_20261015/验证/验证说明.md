# 底层能力验证说明

这些脚本用于验证报错助手的部分技术通路，并非产品、模型对照实验或真实软件自动修复完成品。

`run_probe.py` 使用 Python 标准库，调用现有 PowerShell、Node.js 和 Chrome 或 Edge，不安装依赖，不调用模型 API，不安装终端 Hook 或浏览器扩展。需要 Windows、Python 3、支持全局 WebSocket 的 Node.js，以及脚本中指定路径的浏览器；其他安装位置需要修改路径。

运行方式：在本目录执行 `python -X utf8 run_probe.py`。每次创建独立运行记录，测试文件仅在该记录目录内。`latest-run.json` 指向最近一次运行结果，旧记录保留。

检查内容包括：新增日志文件的监听、Windows Application 未来事件订阅注册、UIA COM 激活、受控子进程错误捕获、独立无头浏览器的 CDP 异常与网络事件，以及合成任务的确定性配置修复、独立输出校验和配置恢复。

本轮结果位于 `运行记录/20261015-143853/results.json`。事件订阅仅注册和关闭，没有注入系统事件；UIA 仅创建对象，没有读取真实窗口。浏览器使用独立资料目录和本机回环页面，没有使用日常登录状态。修复对象是本次创建的测试配置，没有使用 AI 推理。

脚本通过 `Browser.close` 关闭自己的测试浏览器；异常情况下只终止本次创建进程的 PID 及子进程，不按名称结束其他浏览器。浏览器资料目录默认保留，本次后续清理被执行策略拒绝，因此原目录未删除。交付 ZIP 排除该目录和浏览器内部日志，保留探针、配置样例及结果。

这些结果不能用于宣称：已经读取所有软件报错、已经验证真实窗口错误识别、已经支持任意模型接口、已经完成真实应用自动修复，或已经具备发布安装包。
