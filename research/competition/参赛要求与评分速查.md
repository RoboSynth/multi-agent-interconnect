## 参赛资格和报名

全球高校、科研院所有正式学籍的在读研究生、本科生、专科生可以参加。每队1—3人，须来自同一学校，不含分校；跨校组队无效。每队设1名队长，指导教师最多2名。报名截止后，成员及教师信息原则上不能调整；同一选手在本主题赛只能参加一队。参赛费500元/队，交通食宿自理。[赛题页第四部分](https://www.aicomp.cn/tracks/tracks-5/4924.html)

报名入口为[官方报名平台](https://reg.aicomp.cn/)。按官网流程，先注册并完善信息，队长选择赛题、填写团队信息及上传参赛承诺书，成员接受邀请，再完成审核、缴费与作品上传。被邀请成员也需注册并完善信息；注册时的身份类型不可随意转换。缴费成功后可按系统流程申请发票，对公转账需要上传凭据等待审核。[报名操作说明](https://www.aicomp.cn/process)

## 赛制和奖项

本主题赛不分地域赛区，统一评审，依次为初赛形式审查、复赛线上评审、全国总决赛。形式审查通过的有效作品进入复赛；复赛必要时会要求在线答疑或补充演示。总决赛原则上线下答辩，晋级后可继续完善作品并提交更新材料。[赛题页第七部分及附件1第1页](https://www.aicomp.cn/tracks/tracks-5/4924.html)

复赛一、二、三等奖分别不超过有效作品的15%、25%、30%，取整计算；一、二等奖晋级全国总决赛。复赛发省级证书。总决赛原则上采用相同的三个比例，以总决赛有效作品为基数，发国赛证书。比例不是保奖承诺。[赛题页第六部分](https://www.aicomp.cn/tracks/tracks-5/4924.html)

通用章程要求作品至少由3名评委独立评分；决赛团队成员原则上全部到场，团队未到场按弃赛处理。申诉需以学校名义提交加盖校章的书面报告并按规定逐级办理。具体到场、答辩及申诉时限仍需跟进赛题后续通知。[章程第26、36、45条](https://www.aicomp.cn/bylaws)

## 选题和作品边界

官方设置四类方向：开源支持的AI应用；AI开发和协作工具；现有开源项目的改进或社区贡献；其他综合创新。选择一个主要方向，允许交叉融合；能够归入前三类的原则上按相应类别申报。项目可以是应用、插件、工作流、工具，也可以是可核验的测试、文档、数据工具或上游贡献。[赛题页第五部分及附件1第1页](https://www.aicomp.cn/tracks/tracks-5/4924.html)

作品需要说明AI承担的实际任务、开源资源的关键作用，以及团队做了什么改进。只换界面、直接部署已有项目或调用通用接口而没有实质贡献，不能充分满足要求。无需为了参赛训练大模型、采购专用硬件或取得专利、企业合同。[赛题页第五部分](https://www.aicomp.cn/tracks/tracks-5/4924.html)

### 团队准备证据的建议

下表是备赛建议，不是官方新增评分项或指定测试数量。

| 对应维度 | 建议准备的证据 |
| --- | --- |
| 场景价值 | 用户具体任务、实际案例、现有做法的不足，避免只写宏观行业背景 |
| 创新设计 | 与原项目或常见方案的逐项比较，指出自己新增或改进的模块 |
| AI与开源融合 | 输入输出示例、资源选择理由、调用关系、自研边界及授权记录 |
| 完成度与效果 | 可重复运行的流程；同条件比较、失败案例、原始测试记录或用户反馈 |
| 复用价值 | 安装运行说明、最小示例、成果边界、维护安排；贡献链接注明当前状态 |
| 材料表达 | 报告、视频和实际程序版本一致；每个效果结论可追溯到证据 |

优先把一个真实问题做成稳定、可复验的完整流程，再扩展功能。演示录屏与独立效果验证可以相互补充，不能把一次成功演示当成整体可靠性结论。

## 报告怎么写

附件2提供的结构可概括为：作品概述，需求与方案，AI及第三方资源选择，实现过程，验证结果，创新与开放价值，许可与安全边界，总结，以及附录。大纲允许按作品实际情况组织，不必机械套用。封面包含队名、编号、作品名、方向和日期。[附件2入口](https://www.aicomp.cn/tracks/tracks-5/4924.html)

附录资源清单应逐项记录资源类型、名称、版本和出处、授权类型、使用及开放方式、许可义务、团队改动和核验状态。第三方API、素材及AI工具也要纳入说明，不能只列软件依赖。采用AI辅助代码或报告制作时，说明工具参与了哪些环节，以及团队如何审阅、修改、测试和核查来源。[附件2第2—5页](https://www.aicomp.cn/tracks/tracks-5/4924.html)

验证可以使用公开数据、模拟流程、典型案例、小规模测试或社区反馈；不强制企业试点。报告同时写清效果和未解决问题。上游贡献需提供链接与状态，没有上游贡献时，可解释成果如何供他人复用；商业化规划不是必填项。[附件2第3—4页](https://www.aicomp.cn/tracks/tracks-5/4924.html)

## 匿名和成果开放

附件1禁止评审材料出现学校名称、校标和指导教师信息；通用章程第44条进一步要求匿名版不得含参赛人员姓名等可识别身份的信息。建议评审版以队伍编号、成员代号描述分工；报名表和承诺书仍按系统要求填写真实资料。仓库账户、提交记录与真实身份的关联如何兼顾匿名评审，官方当前文件未详细规定，需向赛题联系人确认。[大赛章程](https://www.aicomp.cn/bylaws) · [附件1入口](https://www.aicomp.cn/tracks/tracks-5/4924.html)

参赛时存在合理的权利保护或许可限制，可以受限提交；晋级决赛原则上提供可访问的公开成果或明确开放计划。只开放依法有权发布的部分，不得把第三方资源、账号凭据等一并公开。团队对自有部分和第三方部分的权利需分别说明，不能把整套作品都当然标成自主所有。[赛题页第四部分及附件1第2—3页](https://www.aicomp.cn/tracks/tracks-5/4924.html)

## 提交前逐项确认

- [ ] 队员、指导教师、邀请接受状态和参赛方向已确认。
- [ ] 承诺书、报名审核和缴费状态已确认，保存回执。
- [ ] 报告、视频、成果包指向同一可运行版本。
- [ ] 文件字数、格式、大小及时长符合要求。
- [ ] 评审版完成匿名检查，包括截图、录屏、文件属性及链接暴露的信息。
- [ ] 报告附录列齐资源、许可证、AI工具使用及自研贡献。
- [ ] 测试结论均有对应记录，没有把未合并PR写成已被上游接受。
- [ ] 使用另一台设备或独立环境验证访问和运行说明。
- [ ] 在10月30日20:00前完成提交，并检查平台显示的最终状态。

建议至少提前一天完成首轮上传，为权限、视频压缩和系统审核留出时间；这是团队准备建议，不是官方新增截止时间。
