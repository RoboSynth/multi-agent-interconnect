# 报错助手界面设计与验收

主界面采用类似桌面工具的三列工作台：左侧是接入和工作区，中间是故障列表，右侧展示选中故障从发现到恢复的过程。界面首先回答用户当前是否需要处理问题，不采用大幅营销标题或虚构统计。

配色为雾白 #F5F7FA、墨蓝 #23324B、湖蓝 #2266C5、松绿 #23715C、赭红 #BE4B42、边界灰 #DDE3EC。蓝色表示正在处理，绿色只表示通过验收的恢复，红色用于未恢复故障。字体采用 Windows 的 Microsoft YaHei UI 与 Segoe UI；日志内容单独用等宽字体。

中心视觉是选中故障的处理过程与结果。故障列表按实际状态组织，支持键盘选择。接入权限、模式、模型连接和验证结果都应对应真实状态。空列表显示接入入口；未配置模型时解释可用功能，并提供独立且明确标记的模拟模型演示。

首次验收覆盖：首次配置、工作区授权、自动修复模式、模拟模型说明、故障自动出现、诊断步骤、计划确认、成功复验、修复失败与回退、手动撤销冲突、API 设置保存和错误提示、日志监测开始/停止、任务运行/取消、浏览器接入状态、应用退出与重启。

功能检查和截图检查分开进行。至少额外检查两个反例：配置被用户同时修改时不得覆盖；已存在的旧输出文件不能被误判为本轮成功。真实模型调用与模拟模型结果分开记录。
