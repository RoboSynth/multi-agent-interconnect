## 从哪里修改

`可编辑正文/`用于阅读与批注，`编写源文件/PLAN_expanded.json`、`REPORT_expanded.json`、`EVIDENCE_expanded.json`用于生成PDF。修改JSON正文后重新运行排版脚本，Markdown和PDF会一起更新。

每份文档按章节保存标题和内容块。段落用`p`，小标题用`h`，来源注用`note`，表格用`table`，图示用`diagram`，原始截图用`image`。`引用图像/`保存本稿使用的图片。

## 生成与检查

在本目录执行：

```powershell
python -m pip install -r .\编写源文件\requirements.txt
python .\编写源文件\build_expanded.py
python .\编写源文件\render_expanded.py
python .\编写源文件\check_layout_text.py
```

只改一份时，在生成命令后加`PLAN`、`REPORT`或`EVIDENCE`。渲染需要Poppler；可加入PATH或通过`--pdftoppm`指定路径。Windows默认使用宋体和微软雅黑，其他字体通过`MATERIAL_BODY_FONT`、`MATERIAL_UI_FONT`、`MATERIAL_BOLD_FONT`指定。
