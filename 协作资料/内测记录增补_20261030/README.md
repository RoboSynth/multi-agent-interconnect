# 佐证材料内测增补版

[阅读27页佐证材料](PDF/AIC-2026-23708513-智能体互联-联枢多智能体协同运维系统-佐证材料-内测增补版.pdf)。

本版以提供的24页大赛模板稿为基础，新增附录C“首次使用测试与反馈”，编号E16，内容在最后3页。目录、概要、证据清单和工程质量对照已接入新增记录。

封面团队名称说明行已删除。附录B增加项目仓库地址，并写明比赛结束后公开。

内测来源为[讨论#6](https://github.com/RoboSynth/multi-agent-interconnect/discussions/6)及其操作评论。记录包括配置校验、8项选定测试、未连接工作台交互，以及解释器选择、Docker检查和界面排障三类建议；操作方式保留原帖中的Codex代操作说明。原帖和评论正文也保存在PDF附件中。

`内测增补正文.md`用于批注；`编写源文件/内测增补.json`为新增内容，`build_with_trial.py`负责按原稿版式生成整册PDF。原24页底稿与讨论导出在`原始记录/`，核对结论在`核对记录/`。

在Windows中安装`编写源文件/requirements.txt`所列依赖后，运行：

```powershell
python .\编写源文件\build_with_trial.py
```

生成器使用Windows自带宋体、黑体与Times New Roman。原E01至E15的运行记录、版本与数据按底稿保存；E16按10月30日的独立测试版本记录。
