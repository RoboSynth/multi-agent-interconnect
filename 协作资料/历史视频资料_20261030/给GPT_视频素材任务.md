# 给 GPT：参赛视频素材采集任务

视频由 Claude 合成。Claude 用的是“数据驱动”的做法：动画里的每个光点、每个数字都来自真实记录，录屏的镜头推拉也按真实点击时间对齐。所以需要的不是随手录屏，而是**脚本化采集的干净录屏 + 带时间戳的原始事件**。

所有产出放在 `D:\AI + 开源\参赛视频\素材\`，按下面的子目录命名。每完成一项回复“完成 / 文件路径 / 问题”。

## 总规则

1. **不伪造、不修改数据。** 录屏必须是真实页面和真实运行；只允许用 CSS 遮挡个人信息（账号名、邮箱、头像），不得改动页面上的任何数据、状态或名次。遮挡了哪些元素写进 `素材/遮挡说明.md`。
2. **匿名：** 画面和导出文件中不得出现学校名称、校徽、队员和老师姓名、本机用户名路径、GitHub 账号名。
3. **同一身份同一时间只能有一个消费者。** 需要运行故障时，用 `eval/leased_batch.py` 或租约交接暂停巡检，结束后恢复，暂停时段写进记录。
4. **浏览器统一：** Playwright（Chromium），视口 1920×1080，`deviceScaleFactor: 2`，录像用 `recordVideo`（1920×1080）。页面缩放 125%，隐藏滚动条（只注入 `::-webkit-scrollbar{display:none}`）。
5. 每段录制同时导出 `actions.json`：每次点击、滚动、页面切换的**时间戳（相对录像开始的秒数）和目标元素的屏幕坐标框**。Claude 用它对齐镜头推近和高亮框。

## 任务

### V1 注册平台（`素材/V1-registry/`）

- 用已登录的会话打开 `https://wt.ioa.pub/registry/` → 我的智能体列表，缓慢滚动，七个身份都显示“已通过”；再依次打开协调者和数据库主智能体的详情页，各停 3 秒在 AIC、技能、端点区域。
- 产出：`video.webm`、`actions.json`、每个停留点一张 2 倍分辨率截图（`*.png`）。
- 遮挡右上角账号信息。

### V2 发现与能力确认（`素材/V2-discovery/`）

- 在云端协调者上执行一次**只读** ADP 发现（按 `incident.*`、`db.*`、`ops.*` 技能），保存原始响应（去掉证书、私钥等字段后）`adp-response.json`。
- 再执行一次 describe 能力确认，保存每个参与者返回的能力描述 `describe-*.json`。
- 用 asciinema 录制这两条命令的终端过程，产出 `terminal.cast`（不要用屏幕录像，Claude 会按统一风格重新渲染终端）。

### V3 主案例：复合故障 F10（`素材/V3-f10/`，最重要）

在云端跑一次完整的 F10（与 10-20 那次同样的方法和参数），**同时**做两件事：

1. Playwright 打开工作台（`ssh -L 8877:127.0.0.1:8877` 后访问本地 8877），在“证据与计划 / 操作与接续 / 业务结果”三页之间按处理进度切换，录完整过程；审批弹窗出现时停留 2 秒再点批准。
2. 导出本次运行的全部原始事件：协调者 `events.jsonl`、双端 access 日志、审批记录（只保留时间和动作，不要签名值）、业务观察器每秒请求结果（时间、HTTP 状态、成功与否）。

产出：`video.webm`、`actions.json`、`events.jsonl`、`access/`、`approvals.json`、`order-samples.json`（每秒一条），以及 `run.json`（事故编号、开始与结束时间、批次名）。录像和事件必须是**同一次运行**，`run.json` 里记录两者的起始时间差。

### V4 接管案例（`素材/V4-takeover/`）

跑一次 E1-a `after_applied`（修改完成后主智能体中断）：

- 导出：主智能体退出时间与退出码、协调者判定失联的时间、ADP 重新发现、备用入群、交接包下发、账本返回 `skipped_already_applied` 的时间、旧进程复活后被 fence 拒绝的记录（若本例包含）、最终业务验证结果。整理成按时间排序的 `takeover-timeline.json`。
- 同时录工作台“操作与接续”页（若有画面），产出 `video.webm`。

### V5 访问数据（`素材/V5-access/`）

1. 用公开接口 `https://wt.ioa.pub/internal/matched-stats/top`，startAt 固定为 `2026-09-24T00:00:00+08:00`，endAt 从云端上线时刻（2026-10-20 07:00）起**每小时取一次**直到现在，导出本队七个 AIC 在四个榜（含 / 不含内部的调用榜、被调用榜）上的累计数和名次，以及每个时刻榜首的数值：`ranking-hourly.json`。
2. Playwright 录梧桐首页：滚到“调用排行榜”，依次切换四个榜，停在本队名次 3 秒。产出 `video.webm`、`actions.json`、停留截图。
3. 云端 7×24 运行统计：上线以来巡检次数、成功率、各身份心跳覆盖率、重启自动恢复记录：`longrun-summary.json`。

### V6 安全（`素材/V6-safety/`）

- E2-c 越权拦截的逐条结果（14 次拒绝 + 1 次合法放行，每条：调用方类型、尝试的动作、拒绝原因）：`policy-denials.json`。
- 协调者凭据扫描结果：`credential-scan.json`。
- 审批弹窗的 2 倍截图 `approval.png`（V3 里截到即可）。

### V7 开源贡献（`素材/V7-opensource/`）

- Playwright 录 / 截官方仓库 PR #13、#14 页面和 Issue #15–#18 列表，AtomGit 有提交也一并截图。遮挡账号名和头像。
- `contributions.json`：每个 PR / Issue 的标题、状态、改动行数、链接。
