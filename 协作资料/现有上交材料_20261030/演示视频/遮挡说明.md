# 本轮素材的匿名处理

本目录供队内剪辑和材料修改使用。浏览器录制为 Chromium、1920×1080、页面缩放 125%；截图为 3840×2160。原始页面和响应中的身份信息只在工作区内部缓存保留，浏览器登录状态、私钥、证书、原始 trace 和未脱敏快照不进入本目录。

## V1 注册平台

- 用 CSS 隐藏右上角账号区域 `.horizontal-header-right .el-dropdown`。
- 用 CSS 遮住详情表格中的完整 AIC。
- ACS 是页面原来的文本框，没有替换其 JSON 内容。根据原字体和换行位置，用覆盖块遮住 AIC、provider 姓名和含身份的端点 URL 行；滚动时同步覆盖位置。
- 智能体作品名称、技能、版本、“已通过”状态、时间、AMQP 和 mTLS 字段保持原样。
- `endpoints-video.webm` 是补充阅读端点安全和传输字段的真实录屏，配套时间记录是 `endpoints-actions.json`。

## V5 访问排名

- 用 CSS 遮住排行榜第一列的全部身份码；四项数值、排序、页面统计时间与原始行顺序保持原样。
- 合作单位卡片中的名称和标志用 CSS 遮挡，卡片占位保留。
- 本队定位保存在 `ui-observation.json` 的角色代号和坐标里。`table_position` 是当前页面排序后的行位置，不冒充官方 API 的排名字段。
- A01—A07 是七个本队角色的匿名代号，外部身份在数据文件中使用不可逆摘要代号。

## V7 开源贡献

作者、头像、个人主页链接、参与者与来源分支中包含的个人账号使用 CSS 遮挡。PR 标题、Open 状态、改动行数、文件数及 Issue 状态不变。具体选择器、检查点与修正记录见 `V7-opensource/遮挡说明.md` 和 `capture-verification.json`。

## V2 / V3 / V4 / V6

云端取证按同一次独占租约运行整理。共享数据将真实身份映射为角色代号，隐藏个人信息、机器路径和含身份端点；去除私钥、证书正文、签名值等凭据材料。模型用量、审批时间、业务结果、任务状态和退出码按原记录显示。

V3/V4使用工作台前端展示该次运行事件和工具返回结果，身份以A01至A07代号显示。剪辑说明附有观察页面来源与审批方式。

V6的审批截图取自V3审批弹窗；本地权限测试、凭据扫描和审计检查见`V6-safety/scope.md`。

异常、未知结果和重试记录见对应JSON与素材说明。

## 本次Store、访问统计与证据卡补充

- Store补录使用 `采集脚本/store-masks.cjs` 在首帧前安装遮挡：卡片发布者、详情AIC/发布者/端点、原始ACS入口与学校标志；名称、在线状态、版本、已启用和能力清单保留。实际选择器与检查见 `V2-discovery/store-observation.json`。
- 访问查询使用 `采集脚本/collect_v5_status.cjs` 隐去AIC输入框内容、排行榜身份列、合作单位标志；统计数值、状态和时间字段保持平台原样。平台弹框定位未适配125%页面缩放，采集时仅将原弹框居中，防止右侧数字被裁切。素材来自官方公开统计查询页。
- F10两张新增4K卡由已匿名化的同次记录生成，标“运行记录”；角色用A01/A03，订单路径的同一测试订单编号显示为[order-id]；请求方法、状态、结果及范围不变。
- 导航、遮挡和版式准备阶段的录像存放在私有缓存；演示素材采用已完成的F10与接管实验。
- 已检查补图及录屏关键帧；导出成片后检查全部画面、字幕与音轨。
