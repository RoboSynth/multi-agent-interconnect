# V7 画面匿名与采集说明

本段来自官方 GitHub 仓库的真实公开页面。使用独立、未登录的 Chromium 会话，视口 1920×1080，设备像素比 2，页面缩放 125%；录像为 1920×1080，截图按设备像素导出。

在页面首次渲染前注入 CSS，并通过 MutationObserver 保证遮挡样式持续存在。只对以下身份元素使用 `visibility:hidden`，保留其布局空间：

- PR 作者、评论者、提交者、参与者的用户链接和头像。
- GitHub 首次服务端渲染时尚未带用户属性的 PR 作者区域。
- Issue 列表的作者按钮。
- PR 来源分支及来源仓库所属个人账号，包括新旧两种页面结构和关联提示。

官方仓库名、目标分支、PR/Issue 标题、Open/Completed 状态、提交数、改动文件数、增删行数、评论数、正文与代码没有修改。页面仅隐藏滚动条，没有替换数据或页面内容。

Issue 列表使用公开筛选 `is:issue created:2026-10-18T08:29:20Z..2026-10-18T08:29:40Z`，实际返回 #15–#18 四条；#16 的 Completed 状态保留。该筛选只选择对应贡献记录，不修改其状态。

`actions.json` 保存真实导航、点击、滚动、截图停留的时间和坐标。点击时间来自浏览器事件；视频起点由录制帧与视频包时间估计，精度限制见该文件。原始 DOM 快照、trace 和详细选择器留在私有缓存，不随素材交付。

首次试录被初始作者遮挡检查拦下，片段已归档到私有缓存；修正初始 DOM 选择器后重新采集。此情况属于页面采集检查，不是业务实验重试或业务结果。
