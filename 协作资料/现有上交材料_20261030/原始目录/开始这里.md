## 重新生成PDF

在“上交材料”目录打开终端，准备Python与依赖：

```powershell
python -m pip install reportlab pypdf pillow
python -X utf8 .\原始目录\排版脚本\build_materials.py
```

Windows默认使用系统宋体、微软雅黑和微软雅黑粗体。其他环境可通过`MATERIAL_BODY_FONT`、`MATERIAL_UI_FONT`、`MATERIAL_BOLD_FONT`指定兼容的TrueType字体文件。

安装Poppler并将`pdftoppm`加入PATH，或用`MATERIAL_PDFTOPPM`指定可执行文件，然后运行：

```powershell
python -X utf8 .\原始目录\排版脚本\render_materials.py
```

检查所有受改动影响的页面，确认表格、图示和截图清晰；按新生成记录核对页数、字数和结果。
