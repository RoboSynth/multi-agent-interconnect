# 架构图与任务中断处理图

图示从`原始目录/排版脚本/build_materials.py`的`Diagram`类导出，与技术报告保持一致。

| 文件 | 内容 | 用法 |
| --- | --- | --- |
| `图1-系统架构.svg`、同名PNG | 七个角色、梧桐平台和各角色负责的资源 | SVG可编辑，PNG可插入PPT |
| `图2-任务接续流程.svg`、同名PNG | 执行中断后查询记录、选择备用和处理结果 | 同上 |

架构图中的模型为可选组件。10月29日故障演示按预设顺序检查，模型调用为0。处理图包含已执行、未执行和结果待核对三种情况；本次接管案例展示“修改已完成、备用跳过”的情况。

修改图中文字后，从权威绘图源重新导出：

```powershell
python -X utf8 -B .\scripts\figures_export.py
```

单独解压时，用`--source`指定原交接包中的`原始目录/排版脚本/build_materials.py`。环境需要reportlab、Pillow和Poppler。字体使用微软雅黑或思源黑体。图源、尺寸与文件校验信息见`图源说明.json`。
