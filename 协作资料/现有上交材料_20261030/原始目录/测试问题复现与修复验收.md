## 问题二 本地执行进程出现一次启动异常

```text
RuntimeError: domain worker failed: RuntimeError
```

独立重试发生于16:21:44至16:21:49并通过。合计4次执行、3次成功、1次启动失败，覆盖3种中断点；启动失败的原因待定位。


```powershell

```

测试使用本地AIP stdio智能体与MCP子进程，资源为隔离JSON文件。脚本会在新目录生成策略、测试审批配置、操作记录和资源文件。成功终态为 `read_only=false`、`modifying_calls=1`；旧fence重放返回 `rejected_stale_fence`。
