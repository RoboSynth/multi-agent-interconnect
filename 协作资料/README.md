# 联枢项目协作入口

本分支收录联枢项目的开发源码、运行证据、现有材料和扩充稿，供队友阅读、批注和继续制作。

| 入口 | 内容 |
| --- | --- |
| [扩充稿](扩充材料_20261030/README.md) | 9页技术方案、27页技术报告、23页佐证；可编辑正文、生成源和引用图片 |
| [现有材料](现有上交材料_20261030/原始目录/开始这里.md) | 10月30日整理的既有PDF、源码快照、原始证据、PPT制作资料、图卡与配音 |
| [历史视频资料](历史视频资料_20261030/) | 较早样片、字幕、脚本和补充记录，保留原来的时间与层次 |
| [开发源码](../README.md) | 当前项目代码、依赖、部署、测试及已有开发改动 |
| [给队友的说明](给队友的协作说明.md) | 修改顺序、证据入口和协作要点 |

本分支以c88b203为基础，收录本地开发中的代码、文档和新增记录；历史文件清单沿用各自采集日期。

现有材料与扩充稿各自保存。视频当前旁白与字幕见现有材料中的`演示视频/内容重编资料_20261030/`；扩充稿的正文见`扩充材料_20261030/可编辑正文/`。

共享配置采用合成身份和示例参数。运行联调时按`docs/collaboration-config.md`填写实际配置；外部调用目标可通过`LIANSHU_EXTERNAL_TARGET_AIC`设置。

重复ZIP已展开为实际文件，缓存、私有运行配置和本机备份保存在本地。原始数据中的身份按固定合成编号替换，时间、数字和记录关系保留。
